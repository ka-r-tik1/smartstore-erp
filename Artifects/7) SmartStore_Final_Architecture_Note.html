SmartStore ERP — Architecture Note

Product: SmartStore ERP (FMCG) Decision: Local-First (1-2 clients) → Cloud (3+ clients) Date: March 2026 UI Compatibility: Verified
1

Kya Ban Raha Hai — One Line

Final Decision
Web App jo offline bhi chale, phone pe app jaisa dikhe, PC pe Tally jaisa feel kare — sab ek codebase mein.
✓
NOT a PC-only software (like Tally) No .exe, no CD, no installation wizard. Browser mein kholo, "Install" click karo — done.
✓
NOT a cloud-only app (like Zoho) Internet nahi hai toh bhi billing, inventory, udhaar — sab chalta hai. Data PC mein safe.
2

Two-Phase Plan — Ab vs Baad Mein

Phase 1: Ab (0-2 Clients) Phase 2: Jab 3+ Clients Aaye
Backend FastAPI on localhost (Kartik ka PC) FastAPI on VPS (cloud)
Database SQLite (ek file — PC mein) PostgreSQL (cloud server)
Backup Google Drive auto-sync (FREE) Server + Google Drive dono
Access Kartik ka PC (localhost:8000) — 1-2 clients tak Kahin se bhi (smartstore.alphenta.com) — 3+ clients
Code Change ZERO — SQLAlchemy ORM use karenge, DB switch = 1 line change
Monthly Cost Rs 0/mo Rs 500-800/mo

Master Flow — Phase 1 (Ab, Rs 0/mo)

STEP 1: User Opens App
Cashier / Owner → Chrome Browser → localhost:8000
Browser mein khulega — same UI jo abhi hai (18 modules, glassmorphism)
↓
STEP 2: User Does Something (Bill, Stock Update, Payment)
UI Button Click → fetch() API Call → FastAPI Backend
UI se JSON request jayegi → FastAPI process karegi
↓
STEP 3: Data Save
FastAPI → SQLAlchemy ORM → SQLite File (PC mein)
database.sqlite — ek file mein poora database. PC mein safe.
↓
STEP 4: Auto Backup
SmartStore Folder → Google Drive Desktop Sync → Cloud Backup (FREE)
Google Drive desktop app auto-sync karta hai — kuch karna nahi padta
4

Master Flow — Phase 2 (Client Aaya, Rs 500-800/mo)

STEP 1: Client Opens App
Client ka PC / Phone → Chrome Browser → smartstore.alphenta.com
PWA install — phone pe app icon, PC pe desktop shortcut
↓
STEP 2: API Calls
UI (PWA) → Internet → VPS Server (FastAPI)
↓
STEP 3: Data Save
FastAPI → SQLAlchemy ORM → PostgreSQL (Cloud DB)
Same code — sirf connection string change: sqlite:/// → postgresql://
↓
STEP 4: Offline Mode (Internet gaya)
No Internet → Service Worker catches → IndexedDB (local save)
↓
Internet wapas aaya
IndexedDB Queue → Background Sync → PostgreSQL (Cloud)
Cashier ko pata bhi nahi chalega. Auto sync. Zero data loss.
5

Disaster Recovery — Kya Hoga Agar...

SCENARIO 1: PC Hang / Format Ho Gaya
PC Dead → Naya PC le aao → Google Drive Login → Sab files download
SQLite file + code + invoices — sab Google Drive se wapas. 10 min mein ready.
SCENARIO 2: Internet Nahi Hai (Phase 1)
No WiFi → Koi farak nahi!
Phase 1 mein sab localhost pe hai. Internet ki zaroorat hi nahi. Full offline.
SCENARIO 3: Internet Nahi Hai (Phase 2 — Client live)
No WiFi → PWA + IndexedDB → Local mein kaam karo → WiFi aaya → Auto Sync
Billing, inventory, udhaar — sab chalta hai. Sync baad mein automatic.
SCENARIO 4: VPS Server Down (Phase 2)
Server Crashed → Client ka PWA offline mode → Kaam chalu rahe → Server fix → Auto sync
Client ko pata bhi nahi chalega server down tha. PWA handles it.
