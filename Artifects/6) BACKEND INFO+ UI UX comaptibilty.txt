### 1. SECURITY `/security`
**Kya karta hai:** Har line of code mein XSS, SQL injection, CSRF, auth vulnerabilities check karta hai

**Tumhare project mein kahan lagegi:**
| ERP Area | Security Skill kya karega |
|---|---|
| JWT Login (owner/cashier/staff) | Password hashing, token expiry, refresh tokens, role middleware |
| POS Billing | Payment data sanitization, Razorpay webhook signature verification |
| GST e-Invoice | NIC portal API key management, GSTIN validation |
| Dealers/Udhaar | SQL injection prevention on search queries |
| WhatsApp Chatbot | Gupshup webhook auth, input sanitization |
| File Upload (bank CSV, invoices) | Path traversal prevention, file type validation |
| All API endpoints | Rate limiting, CORS config, security headers |

**Kab activate hogi:** Automatically — jab bhi auth code, API endpoint, DB query, ya form handling likhoge
**Slash command:** `/security [area to review]`
**Usefulness: 10/10** — Without this, ERP hack ho sakta hai. Payment data + GST data = highly sensitive.

---

### 2. SCALABILITY `/scalability`
**Kya karta hai:** Database indexing, caching, API pagination, N+1 query fixes, connection pooling

**Tumhare project mein kahan lagegi:**
| ERP Area | Scalability Skill kya karega |
|---|---|
| PostgreSQL schema | Proper indexes on product_id, invoice_date, dealer_id, location_id |
| Inventory queries | N+1 fix — stock levels across 18 modules hitting same tables |
| POS Billing | Connection pooling — multiple cashiers billing simultaneously |
| Dashboard KPIs | Redis caching for today's sales, pending orders (don't hit DB every refresh) |
| AI Demand Forecast | Query optimization for monthly aggregation across lakhs of rows |
| Multi-location | Partitioning strategy when 100+ stores |
| Orders/Sales | Cursor-based pagination — not OFFSET (slow on large tables) |
| Bank Reconciliation | Batch processing for CSV with 10,000+ rows |

**Kab activate hogi:** Jab bhi DB query, API endpoint, caching, ya background job likhoge
**Slash command:** `/scalability [area to optimize]`
**Usefulness: 9/10** — 1 store = fine. 10+ stores = without this, app will be slow/crash.

---

### 3. COST-REDUCER `/cost-reducer`
**Kya karta hai:** Cloud cost optimization, right-sizing, caching ROI, bundle optimization

**Tumhare project mein kahan lagegi:**
| ERP Area | Cost Reducer Skill kya karega |
|---|---|
| VPS server | Right-size: 2GB vs 4GB RAM — kya chahiye really? |
| PostgreSQL | Query optimization = less CPU = cheaper server |
| S3 storage | Invoice PDFs lifecycle policy — old invoices → cheaper storage tier |
| Product images | WebP/AVIF conversion — 60% smaller = less bandwidth bill |
| API responses | Gzip compression — less data transfer cost |
| WhatsApp API | Message batching — Rs 0.50/msg × 1000 dealers = Rs 500/day if not optimized |
| Razorpay | Webhook retry optimization — avoid duplicate processing charges |

**Kab activate hogi:** Jab cloud resources configure karo, DB queries likho, caching set karo
**Slash command:** `/cost-reducer [area to optimize]`
**Usefulness: 9/10** — Tumhara budget Rs 600-1000/mo hai. Har rupaya matters.

### 7. n8n `/n8n`

**Tumhare project mein kahan lagegi:**
| Automation | n8n kya karega |

**Kab use hogi:** Phase 2 — jab basic backend ready ho, automations add karo

### 8. TRIGGER.DEV `/trigger-dev`
**Kya karta hai:** TypeScript background jobs — queues, retries, scheduling

**Tumhare project mein kahan lagegi:**
| Background Job | Trigger.dev kya karega |
|---|---|
| Invoice PDF generation | Queue → ReportLab → Save PDF → Return URL |
| GST e-Invoice IRN | Queue → NIC API call → Retry on failure → Save IRN |
| Bulk WhatsApp reminders | Batch 500 dealers → Rate limit → Send sequentially |
| AI demand forecast | Nightly cron → Run forecast model → Cache results |
| Bank recon processing | Upload CSV → Queue → Match 10,000 rows → Report |

**ISSUE:** Trigger.dev is **TypeScript** but your stack is **Python/FastAPI**. 
**Alternative:** Use **Celery + Redis** for Python background jobs instead.
**Usefulness: 5/10** — Concept is useful but tech mismatch. Celery is better fit.
